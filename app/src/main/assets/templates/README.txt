Template folders can now use a manifest-driven structure:

template-folder/
  template.json
  background.png
  overlay_2x2.png
  overlay_2x3.png
  overlay_2x4.png

Required manifest fields:
- `name`
- `background`
- `overlays`

Example:
Downloads/KawaiiPB/Templates/SpringBloom/template.json
Downloads/KawaiiPB/Templates/SpringBloom/background.png
Downloads/KawaiiPB/Templates/SpringBloom/overlay_2x4.png
